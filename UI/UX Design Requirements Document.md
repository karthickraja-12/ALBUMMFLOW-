# Design Philosophy

AlbumFlow should feel:

* Professional
* Premium
* Fast
* Clean
* Trustworthy

Avoid:

* Heavy gradients
* Neon colors
* Glassmorphism
* Excessive animations
* Cluttered dashboards

Design Inspiration:

* Linear
* Stripe
* Notion
* Apple
* Framer
